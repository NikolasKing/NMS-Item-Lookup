**[Русский](#русский) · [English](#english)**

## Русский

**NMS Item Lookup** — бесплатная настольная программа для Windows (64-bit), которая помогает найти название предмета из **No Man's Sky** на русском или английском языке и скопировать его внутренний **Item ID** для использования в **GoatFungus Save Editor**.

### Возможности

- Поиск по русскому названию, английскому названию или Item ID.
- 5 165 записей в каталоге, из них 4 939 — с русскими названиями.
- Точные совпадения в начале результатов; фильтрация по категориям.
- Предпросмотр иконок предметов.
- Копирование английского названия или Item ID одним нажатием.
- Автономная программа с графическим интерфейсом, без необходимости устанавливать Python, Node.js или Java.

### Скачать и запустить

1. Откройте **[Releases](../../releases)** и скачайте архив `NMS_Item_Lookup_v0.6.2_QA_ONLY.zip` из версии **v0.6.2**.
2. **Распакуйте весь внешний ZIP** в отдельную папку. Не запускайте программу прямо из архива.
3. Запустите файл `NMS_Item_Lookup_v0.6.exe`. В окне программы отображается версия **v0.6.2**.
4. Введите, например, **Индий** — получите **Indium / BLUE2**. Для активированного индия: **Activated Indium / EX_BLUE**.

**Важно:** рядом с EXE должны оставаться `nms-lookup-cache.json`, `iconmap-v0.6.json` и вложенный архив `nms-item-icons-v0.6.zip`. Сам вложенный ZIP дополнительно распаковывать не требуется.

**Статус проверки:** разработчик подтвердил запуск и работу готового ZIP в Windows и на втором компьютере. Точное окружение второго компьютера не документировано.

**Стоимость:** бесплатно. Добровольная поддержка автора приветствуется, но необязательна; реквизиты для поддержки будут опубликованы отдельно.

## English

**NMS Item Lookup** is a free, standalone Windows (64-bit) desktop application for finding **No Man's Sky** items by their Russian or English names and copying internal **Item IDs** for use with **GoatFungus Save Editor**.

### Features

- Search by Russian name, English name, or Item ID.
- 5,165 catalog records, including 4,939 with Russian names.
- Exact matches shown first and category filters.
- Item icon previews.
- One-click copy for English names and Item IDs.
- Standalone GUI: no Python, Node.js, or Java installation required.

### Download and run

1. Open **[Releases](../../releases)** and download `NMS_Item_Lookup_v0.6.2_QA_ONLY.zip` from **v0.6.2**.
2. **Extract the entire outer ZIP** to a folder. Do not run the app from inside the archive.
3. Run `NMS_Item_Lookup_v0.6.exe` (the application's window identifies it as **v0.6.2**).
4. Try **Indium** → **BLUE2**, or **Activated Indium** → **EX_BLUE**.

**Important:** keep `nms-lookup-cache.json`, `iconmap-v0.6.json`, and the nested `nms-item-icons-v0.6.zip` alongside the EXE. You do not need to extract the nested ZIP.

**Verification:** the author confirmed that the ZIP runs and works on Windows and on a second computer. The second computer's exact environment has not been documented.

**Pricing:** free to use and share. Optional donations are welcome, but never required; support details may be added later.
